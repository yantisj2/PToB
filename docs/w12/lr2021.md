# W12 LR2021 receive wiring

Copyright (c) 2026 Jonathan Yantis. MIT.

The W12 radio front end differs from N30's SX1262 board. Version0.2.1 uses
LR2021 **DIO8 → ESP32 GPIO14** for RX_DONE capture on fine-counter CH1.
GPIO7 is the alternative DIO7 connection; it is not DIO11. GNSS retains its
group0 timer and existing RX39/PPS41/power profile.

The GC1109 sub-GHz front end uses DIO9 for CTX, DIO10 for CPS and DIO11 for
CSD. During RX, DIO11 is high and DIO9/DIO10 low, enabling the LNA. DIO5/DIO6
are the2.4GHz front-end enables and stay low. Host GPIO4 supplies the GC1109
rail; GPIO3 stays low. Configuration waits a bounded100ms for rail settling,
checking cancellation every10ms. Radio OFF asserts reset and drops both rails,
then requires capture-channel release and actual SPI retirement before OFF ack.

The earlier0.2.0 port incorrectly assigned DIO11 as IRQ and DIO9 as RX enable.
That conflicts with this front end and is not a usable W12 receive mapping.
Its host tests checked ownership, not the real board's RF switch truth table.
The0.2.1 owner fixture now asserts the IRQ pair and all five RX DIO values.

Receiver enable and authenticated source selection remain separate. KEEP ON
cannot override the exact transmitter factory built into the image. RC8
metadata and packets from another emitter remain rejected even with a valid
group MAC. A configured transmitter may rebroadcast a different current GM;
the emitter filter must not be replaced by a filter on the root identity.
