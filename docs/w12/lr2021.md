# W12 LR2021 receive wiring

Copyright (c) 2026 Jonathan Yantis. MIT.

The W12 radio front end differs from N30's SX1262 board. Version0.2.1 uses
LR2021 **DIO8 → ESP32 GPIO14** for RX_DONE capture on fine-counter CH1.
GPIO7 is the alternative DIO7 connection; it is not DIO11. GNSS retains its
group0 timer and existing RX39/PPS41/power profile.

Version0.2.2 separates LoRa's software counter epoch and extension from BLE's
fine receiver. CH1 edges and the LoRa CURRENT reader use the same independent
coordinate, without inspecting BLE pending-edge fences or association history.
The RX worker polls the counter between packets to retain wrap continuity.
This adapts the purpose of N30's independent XTAL-reader fix to W12's available
resources: the physical MCPWM1 timer remains shared, and GNSS keeps group0.
An unavailable LoRa counter cannot fall back to BLE/GPTimer coordinates.

The compact status field `auto=lock/remaining_ms` reports the worker's actual
fresh BLE precision-lock input and the original AUTO transition countdown.
It is diagnostic evidence, not an independent precision measurement.

The GC1109 sub-GHz front end uses DIO9 for CTX, DIO10 for CPS and DIO11 for
CSD. During RX, DIO11 is high and DIO9/DIO10 low, enabling the LNA. DIO5/DIO6
are the2.4GHz front-end enables and stay low. Host GPIO4 supplies the GC1109
rail; GPIO3 stays low. Configuration waits a bounded100ms for rail settling,
checking cancellation every10ms. Radio OFF asserts reset and drops both rails,
then requires capture-channel release and actual SPI retirement before OFF ack.

The earlier0.2.0 port incorrectly assigned DIO11 as IRQ and DIO9 as RX enable.
That conflicts with this front end and is not a usable W12 receive mapping.
Its host tests checked ownership, not the real board's RF switch truth table.
The0.2.1 owner fixture now asserts the IRQ pair and all five RX DIO values.

Receiver enable and authenticated source selection remain separate. KEEP ON
cannot override the exact transmitter factory built into the image. RC8
companion metadata from another emitter is rejected even with a valid group
MAC. Before a companion arrives, functional timing pairs authenticate group
membership and the wire context, but cannot independently establish the full
emitter factory identity; the compiled factory filter cannot prove that absent
metadata. Version0.2.4 follows N30 in exposing that pre-companion functional
time with unknown boots/authority/bounds. An explicit authenticated withdrawal
removes time; missing metadata alone does not. A configured transmitter may rebroadcast a different current GM;
the emitter filter must not be replaced by a filter on the root identity.
