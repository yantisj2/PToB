# Reviewed source references for the multipath paper

Copyright (c) 2026 Jonathan Yantis. MIT.

This collection contains only the 18 code/document files explicitly selected by
the paper's [preparation receipt](../../editions/ble-tail-multipath-2026-10-26.json).
Each `.txt` file preserves the exact original bytes, path and revision recorded
in that receipt. The [publication record](../../editions/ble-tail-multipath-2026-10-26-publication.json)
maps every original file to its snapshot path and records its SHA-256 identity.
The verifier checks all selected bytes against the original preparation seals.

These frozen research references preserve what the paper reviewed. They are not
current operating instructions, a complete firmware release, hardware acceptance
or authorization to use a device. Current target code and build guides live in
the repository's ordinary firmware and documentation collections. Later source
changes cannot silently replace this paper's reviewed checkpoint.

The selection includes public-code timing paths and target guides only. No
private working directory, laboratory history, enrollment, raw capture or enrolled
binary is included. Original code and ordinary documentation use MIT; the archived
LaTeX paper source, this paper, its original figures and analytical supplement
retain CC BY 4.0. Preserved
third-party notices still apply.
