# PToB

PToB is an experimental precision time protocol proposal over Bluetooth Low
Energy. This repository is being prepared as the public home for its research
papers, supporting evidence, and a T096 R2 firmware example.

Project website: [ptob.dev](https://ptob.dev).

| Collection | Purpose | Status |
| --- | --- | --- |
| [Papers](papers/) | Versioned manuscripts and supporting source | Import pending |
| [Protocol](protocol/) | Versioned contracts and executable vectors | Import pending |
| [Evidence](evidence/) | Claim-linked datasets, methods, results, and limitations | Import pending |
| [T096 firmware](firmware/t096/) | Reproducible R2 example and build instructions | Import pending |

No manuscript, evidence dataset, or firmware release is included yet. PToB is a
proposal, not an adopted Bluetooth SIG or IEEE standard. Implementation and
measurement claims will be tied to specific versions and evidence.
