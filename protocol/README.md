# Protocol contracts

Read the [v12-to-R2 background](../docs/V12_TO_R2.md) for the current service
direction. The [draft proposal](../papers/ptob-proposal.pdf) preserves an earlier
protocol edition; it should not be read as the current R2 wire contract.

Canonical contract imports are pending. This collection will hold versioned wire contracts,
machine-readable layouts, golden vectors, and compatibility information.

Every contract identifies its status and supported firmware profile. Proposed,
implemented, installed, and verified behavior are distinct. Illustrative traces
are labeled as synthetic and are not measurement evidence.
