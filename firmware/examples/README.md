# Firmware examples

Small, independent programs for learning individual timing techniques.

Start with [ESP32-REF](esp32-ref/README.md). The first lesson runs entirely on a
host computer. The BLE lessons use the Meshnology W12 ESP32-S3 for hardware
capture and clock tracking.

The examples have their own source and builds. The operational firmware targets,
including [W12](../w12/README.md), retain their separate setup and qualification.
