The [repository policy](../LICENSING.md) describes how these apply.

- `Apache-2.0.txt`: complete Apache License 2.0, copied unchanged from Zephyr's
  LICENSE at pinned commit `7823374e872145b5bd018bfe447839eb36042611`.
  It accompanies files retaining Apache-2.0 notices; it is not the blanket
  license of all project material.
- `TinyCrypt-BSD-3-Clause.txt`: Intel's complete notice extracted from the
  preserved comment in `firmware/w12/main/g1_hmac.c`; the SS3 copy has the same
  notice. Only C comment delimiters were removed from this companion text.

MIT is at the repository root. CC BY 4.0 is linked from the papers and evidence
license notices. Separately downloaded SDKs and chrony retain their upstream
license files; their source archives and binaries are not included in Git.
